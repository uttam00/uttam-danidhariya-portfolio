# 🚀 Uttam Danidhariya Portfolio Website

Welcome to the **personal portfolio** of Uttam Danidhariya — a passionate Frontend Developer specializing in React and Next.js! 🌟

---


## 🖼️ Overview

This portfolio is a modern, interactive, and visually stunning showcase of my skills, projects, and professional journey. Built with the latest web technologies, it features:

- 🎨 **Animated Hero Section**: Eye-catching introduction with dynamic backgrounds and typewriter effects.
- 👨‍💻 **About Me**: My education, passions, and language proficiencies.
- 🛠️ **Skills**: Interactive skill tabs and a creative skill cloud.
- 🚧 **Projects**: Filterable, detailed project cards with live and code links.
- 📬 **Contact**: Modern contact form with validation and direct links to my socials.
- 🌗 **Dark/Light Mode**: Seamless theme toggle for the best viewing experience.

---

## 🏗️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), Framer Motion
- **UI Libraries:** Radix UI, Lucide Icons, Material UI, Ant Design
- **Forms & Validation:** React Hook Form, Yup
- **Other:** TypeScript, Zod, Recharts, Embla Carousel, and more!

---
